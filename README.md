\# STM32 CAN Test



This repository contains a simple two-node CAN communication test using:



\- STM32G474RE NUCLEO boards

\- CJMCU TJA1051 CAN transceivers

\- STM32CubeIDE

\- HAL drivers



\## Repository Structure



\- Node\_A\_TX - CAN transmitter

\- Node\_B\_RX - CAN receiver

\- Common - Shared CAN definitions

\- Docs - Wiring, configuration, and test documentation



Current Status:

\- Node A configured

\- Node B configured

\- Ready for hardware validation
